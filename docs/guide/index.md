## 核心代理能力

基于 **Mihomo（Clash Meta）** 内核，Bettbox 支持完整的主流能力：

- **协议全家桶**：VLESS、Trojan、Hysteria2、WireGuard、SSH 等。
- **规则引擎**：按域名、IP、GEOIP 地理位置、进程名灵活分流。
- **TUN 模式**：以虚拟网卡接管系统流量，无需逐应用配置。
- **Fake-IP / 增强 DNS**：提升首次连接速度，规避 DNS 污染。

---

## 可视化与个性化

- **改动即时生效**：绝大多数参数在可视化界面调整后即时应用，无需手改 YAML。
- **专业编辑器**：内置重构版 **code-forge** 编辑器，支持语法高亮，体验可媲美专业级编辑器。
- **APP首页实时网速小组件**：多款设计精良的 Widget，直观掌控实时网速与运行状态。
- **30 种测速动画**：让等待节点测速的过程也赏心悦目。

---

## 新手建议

> 初次使用时，建议保持所有设置默认，仅通过「导入订阅」开始体验。Bettbox 已预设了最优的默认参数；待熟悉后再逐步探索进阶功能。

:::note 找不到某项设置？
顶部搜索、底部导航与「更多（三个点）」菜单是三大入口。涉及路由/分流的进阶开关多在 **更多 → 路由设置 / 基本配置** 中。
:::
