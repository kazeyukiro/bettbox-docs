# 应用分流

应用分流允许你指定**哪些 App 走代理、哪些 App 直连**。这对解决「网银无法登录」「游戏高延迟」「本地服务访问慢」等场景非常有用。

---

## 工作原理

> **核心逻辑**：你可以自由决定哪些 App 必须走代理（如社交/视频类），哪些 App 必须直连（如 12306、本地银行 App），从而兼顾访问速度与本地服务的兼容性。

- 入口：**更多 → 应用分流**（部分版本位于 **设置 → 路由设置 → 应用分流**）。

---

## 两种模式

| 模式 | 行为 | 典型用法 |
| :--- | :--- | :--- |
| **黑名单模式** | 勾选的应用**直连**，其余走代理 | 只把个别「必须直连」的 App 加进去 |
| **白名单模式** | 仅勾选的应用走代理，其余**直连** | 只想让特定 App 走代理时 |

:::tip 怎么选？
- 想「几乎全部走代理，仅个别本地 App 直连」→ 用**黑名单**。
- 想「默认直连，仅指定 App 走代理」→ 用**白名单**。
:::

---

## 操作步骤

1. **进入设置**：底部导航栏点击 **设置 → 路由设置**。
2. **找到分流选项**：点击 **应用分流**。
3. **选择工作模式**：黑名单 / 白名单。
4. **搜索与勾选**：在列表中找到对应 App（如微信、支付宝、游戏），勾选它们。
5. **保存生效**：设置自动保存。若 VPN 已在运行，建议点击「重启服务」以刷新路由表。

---

## 场景示例

| 场景 | 推荐配置 |
| :--- | :--- |
| 游戏低延迟 | 将游戏加入**黑名单**直连，避免代理绕路 |
| 网银/本地政务 App | 加入**黑名单**直连，规避代理环境登录风险 |
| 海外社交/视频 | 保持走代理（默认或加入白名单） |

---

## 注意事项

- **系统应用**：除非非常了解其原理，否则不建议勾选「系统组件」，这可能导致系统更新失败或推送延迟。
- **混淆应用**：部分 App 有多个进程，若分流不生效可尝试在列表中勾选其全部相关条目。
- **重启服务**：修改后若发现未立即生效，重启 VPN / TUN 服务通常即可刷新路由表。
