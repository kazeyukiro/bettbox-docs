# 常见问题

---

## 安装与安全

**Q：安卓无法后台保活 / 经常断连？**  
A：请检查是否授予充足后台权限，并确认系统 ≥ Android 8.0。部分厂商需手动关闭电池优化、允许自启动与后台运行；应用内「增强工具」也提供电池优化白名单权限的请求入口。

**Q：macOS 提示系统版本过低？**  
A：macOS 最低支持 **12.0**（工程 `MACOSX_DEPLOYMENT_TARGET = 12.0`），请升级系统后再安装。

**Q：桌面端旧电脑运行异常 / 闪退？**  
A：2012 年前后及更早 CPU（如 AMD v1 架构）请下载 **Compatible** 兼容版本：标准包以 `GOAMD64=v3` 编译，兼容版为 `v1`。注意兼容版只提供 **Windows / Linux 的 x64** 包。

**Q：软件是否安全？会不会上传隐私？**  
A：Bettbox 开源（GPL-3.0）、无广告，代码与 CI 公开可审计，已通过 [SignPath](https://signpath.io) 开源基金会人工安全溯源；Windows 端带有 OV 数字签名，零隐私收集。

**Q：从哪里下载才是官方的？**  
A：唯一官方下载源是 [GitHub Releases](https://github.com/appshubcc/Bettbox/releases/latest)。请勿从不明第三方站点下载。

## 桌面端

**Q：Windows 需要管理员权限吗？**  
A：安装版已预先处理权限，**一般无需**再次手动提权。

**Q：无法开启 TUN 虚拟网卡？**  
A：macOS / Linux 请确保输入正确密码完成权限授权（界面提示「启用 TUN 虚拟网卡功能需要管理员或 Root 权限」）；并确认没有其他代理软件 / VPN 占用虚拟网卡或端口。

**Q：启动报错？**  
A：请附上 Debug 信息提交 Issue，并确认没有冲突的代理服务在运行；「更多 → 日志」中可导出日志。

**Q：macOS 安装被系统拦截？**  
A：当前暂未购买 Apple 开发者证书，可能被 Gatekeeper 拦截：
1. **推荐**：在「应用程序」中右键 Bettbox →「打开」→ 确认再次「打开」。
2. **备选**：「系统设置 → 隐私与安全性」中找到 Bettbox，点「仍要打开」。

## 订阅与配置

**Q：无法导入订阅链接？**  
A：先在浏览器验证链接是否可用；重置链接后重试。若订阅经过 Age 加密，请检查是否填写了以 `AGE-SECRET-KEY-` 开头的正确私钥。若 DEBUG 确认是客户端问题，请提交 Issue。

**Q：节点显示为 0？**  
A：配置内可能无有效代理节点，请确认订阅是否已过期，或联系服务商。

**Q：测速无响应 / 节点延迟不显示？**  
A：请前往 **更多 → 外部资源**，确保 GEO 内置资源（GeoIP / GeoSite）已下载完整。

**Q：配置损坏或异常？**  
A：可通过 **更多 → 设置 → 备份与恢复** 从 WebDAV 或本地备份还原（支持「仅恢复配置文件」与两种恢复策略）；也可在配置卡片 **⋮ → 编辑** 中重新上传配置文件。内置「双重配置检测验证」会在配置异常时给出提示。

**Q：手动改的配置被自动更新覆盖了？**  
A：手工编辑配置文件后，应用会询问是否关闭该配置的自动更新；也可改用「覆写」叠加自定义内容。自动更新间隔的单位是**分钟**。

## 功能位置

**Q：找不到「应用分流」/「DNS 设置」？**  
A：界面名称为「**分应用代理**」（更多 → 设置 → 分应用代理）；DNS 在「**更多 → 设置 → 内核配置 → DNS**」。「更多」页顶部提供设置项搜索，可直接输入名称定位。

**Q：小组件能放到手机桌面吗？**  
A：不能。首页小组件是 App 内卡片，源码未实现系统桌面小组件。想在 App 外看状态，可在「增强工具」中开启「在通知栏显示网速和订阅信息」。
