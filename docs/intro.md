# 欢迎使用 Bettbox

**Bettbox** 是一款基于 **Mihomo（Clash Meta）** 内核的多平台代理客户端，由 FlClash 早期版本重构而来。

项目理念：**Better Experience, Out of the box** — 更好的体验，亦开箱可用。

## 项目定位

- **多平台**：Android（含 Android TV）、Windows、macOS、Linux
- **内核**：紧跟 Mihomo 主线，支持规则分流、代理组、TUN 模式等完整能力
- **体验**：前台流畅高帧率，后台低功耗；桌面端低占用，移动端省电无感
- **安全**：开源透明（GPL-3.0）、无广告、无隐私收集；已通过 SignPath 人工安全溯源，Windows 端装载 OV 数字签名

## 核心亮点

| 方向 | 说明 |
|------|------|
| 开箱即用 | 权限与 TUN/VPN 体验预置优化，减少手动调试 |
| 精雕细琢 | UI 与交互细节打磨，多平台一致体验 |
| 增强工具 | 无感智能启停、休眠支持、禁用 QUIC、托盘增强等 |
| 可视化设置 | 参数改动即时生效，无需手改 YAML |
| 个性化 | 主题、图标、标题、30+ 测速动画 |
| 脚本 UI 适配 | 支持外置 JS 覆写脚本的可视化开关 |
| 兼容旧设备 | 持续维护 Compatible 版本，延长老硬件寿命 |
