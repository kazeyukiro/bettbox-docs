# 小组件与个性化

Bettbox 不仅是一个代理工具，也注重「用得顺手、看得舒心」。本页介绍首页 Widget、测速动画、主题图标定制，以及进阶的脚本 UI 适配。

---

## 首页小组件（Widget）

内置多款设计精良的 **Widget** 小组件，让你在桌面 / 锁屏直观掌控：

- **实时网速**：上行 / 下行速率一瞥即知。
- **全局运行状态**：当前连接、已用流量、活跃节点一目了然。

:::tip 移动端
Android 可将 Widget 添加到桌面；配合后台保活，实现「不动 App 也能看状态」。
:::

---

## 30 种测速动画

Bettbox 内置 **30 种精美测速动画**，让节点延迟测试的等待过程也赏心悦目。可在个性化设置中自由切换，找到最契合你审美的那一款。

---

## 主题与图标定制

- **色彩主题**：支持丰富的配色主题，深浅随你。
- **自定义图标 / 标题**：更换 App 图标与显示名称，融入你的桌面风格。
- **个性化开关**：将上述偏好作为内置可视化选项，无需任何配置文件修改。

---

## 脚本 UI 适配（进阶）

自 **v1.18.8** 起，Bettbox 是首个支持 **JS 覆写脚本分流 UI 适配** 的客户端：外置覆写脚本可声明可视化开关，Bettbox 自动渲染为可用界面。

### 最简声明

在你的脚本首行添加：

```js
const Compatible_With_Bettbox = { ruleOptionsEnable: true };
```

即可让 Bettbox 识别并使用内置的可视化开关。

### 声明策略组开关

若脚本同时包含策略组开关与其他功能开关，可用 `policyGroupOptions` 声明哪些属于策略组；未声明的开关会被收进页面末尾的「⚙️ 其他设置」二级页面，策略组开关保持原有列表展示：

```js
const Compatible_With_Bettbox = {
  ruleOptionsEnable: true,
  // 声明属于策略组的开关名称，需与 ruleOptionsEnable 的键完全一致
  policyGroupOptions: ['🚀 节点选择', '🛑 广告拦截'],
};
```

> 未声明 `policyGroupOptions`、或声明的名称与开关不匹配时，展示效果与旧版本完全一致（所有开关平铺展示）。
