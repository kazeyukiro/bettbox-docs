# 节点与代理组

本页介绍如何在 Bettbox 中管理节点、使用代理组、执行延迟测试，以及 TUN / 系统代理、规则分流与 DNS 的基础配置。

---

## 代理组（Proxy Groups）

Mihomo 通过 **代理组** 组织节点与分流策略。Bettbox 在 **代理（Proxies）** 页面以可视化方式呈现所有代理组：

- **select（手动选择）**：在组内节点间手动切换，最常用的「节点选择」组。
- **url-test / fallback / load-balance**：根据延迟自动选节点或负载均衡，无需手动干预。

> 切换代理组即可整体改变某类流量的出口，是规则分流之外的「总开关」。

---

## 延迟测试

1. 进入 **代理** 页面。
2. 点击测速按钮执行延迟测试，节点旁会显示延迟数值（ms）。
3. 测试基于配置中 `proxy-groups` 指定的 `url` 与 `interval`。

:::tip 30 种测速动画
Bettbox 内置 **30 种精美测速动画**，可在个性化设置中切换，让等待测速的过程也赏心悦目。详见 [小组件与个性化](/docs/guide/widgets)。
:::

## 流量接管：TUN 与系统代理

| 模式 | 适用场景 | 说明 |
| :--- | :--- | :--- |
| **系统代理** | 桌面端日常使用 | 仅接管遵循系统代理的应用，轻量。 |
| **TUN 模式** | 全局/游戏/命令行 | 以虚拟网卡接管系统全部流量，无需逐应用配置。 |
| **VPN / TUN（移动端）** | Android / TV | 移动端通过 VPN 服务接管流量。 |

:::caution 开启 TUN 的权限
- **macOS / Linux**：首次开启 TUN 需输入当前登录用户的密码授权。
- **Android**：需授予 VPN 权限，并保持后台运行。
- 若无法开启，请确认没有其他代理软件 / VPN 占用虚拟网卡。
:::

## 规则分流

Bettbox 内置强大的规则引擎，支持按以下维度分流：

- **域名 / 域名后缀 / 进程名**：如 `DOMAIN-SUFFIX,example.com,DIRECT`。
- **IP / GEOIP 地理位置**：如国内流量直连、海外流量走代理。
- **策略组联动**：规则指向某个代理组，由代理组决定最终出口。

绝大多数分流规则随订阅自动生效；如需自定义，可在 [配置编辑](/docs/guide/config#5-进阶编辑配置文件) 中调整 `rules` 字段。

---

## DNS 与 Fake-IP

进入 **更多 → 基本配置 → DNS** 可调整 DNS 行为：

- **Fake-IP 模式**：显著提升首次连接速度，规避 DNS 污染，是多数用户的推荐选择。
- 增强 DNS 配合规则引擎，可在分流前完成域名解析决策。

:::note 内核一致性
上述能力均由 Mihomo 内核提供，Bettbox 仅做可视化封装与体验优化，逻辑与官方 Mihomo 完全一致。
:::
