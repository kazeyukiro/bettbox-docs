# 配置与订阅指南

在 Bettbox 中管理订阅的方式与 FlClash 保持高度一致。无论你使用订阅链接、本地文件还是二维码，都能快速上手。

---

## 1. 自动同步（通过 URL 导入）

这是**最推荐**的方式，支持自动更新节点列表。

**操作步骤：**

1. **复制链接**：从你的服务提供商处获取 Clash / Mihomo 订阅链接。
2. **打开配置**：进入底部导航栏的 **配置** 页面。
3. **点击添加**：点击右下角 **＋** 按钮，选择 **从 URL 导入**。
4. **保存配置**：输入名称与 URL，并设置更新间隔（如 12 小时 / 24 小时）。
5. **激活**：在列表中点击该配置卡片，确认其处于选中状态。

:::tip 加密订阅（Age Key）
若你的订阅经过 Age Key 加密，导入 URL 后还需填写对应的 **私钥** 才能解析。AES 加密仅持有对应私钥的设备可解开订阅文件。详见内核关于 Age Key 的说明。
:::

---

## 2. 手动导入（通过文件导入）

如果你已经下载了 `.yaml` 配置文件，可使用此方法。

1. 点击 **＋** 按钮，选择 **从文件导入**。
2. 在系统文件选择器里定位并选中配置文件。
3. 导入后，文件会存储到 Bettbox 的本地目录中。

---

## 3. 扫描二维码导入

1. 进入 **配置** 页面，点击 **＋** → **扫描二维码**。
2. 两种识别方式：
   - **直接扫码**：将摄像头对准电脑屏幕或其他设备上的订阅二维码。
   - **相册识别**：二维码已保存在设备里时，点击扫描界面的图片图标从相册导入。
3. 识别后确认名称，点击 **保存**。

---

## 4. 自动更新与备份

| 能力 | 说明 |
| :--- | :--- |
| **自动更新** | URL 导入时可设置更新间隔，到期自动拉取最新节点。 |
| **WebDAV 备份** | 支持将配置与订阅备份到 WebDAV，换机/重装后可一键还原。 |
| **双重配置检测** | 内置双重配置检测验证，异常配置会被拦截并提示，避免错误配置导致整体失效。 |

:::caution 迁移到新设备
更换手机/电脑时，建议先通过 WebDAV 或「配置导出」备份，再在新设备导入，避免订阅与个性化设置丢失。
:::

---

## 5. 进阶：编辑配置文件

Bettbox 内置轻量化 **code-forge** 编辑器，允许你直接微调配置。

- **如何操作**：在配置列表中，点击卡片右上角的 **更多（三个点）→ 编辑文件**。
- **适用场景**：手动添加 DNS 规则、修改分流模式、调整自定义策略组。

```yaml
# 示例：在配置中追加一条自定义规则
rules:
  - DOMAIN-SUFFIX,example.com,DIRECT
  - GEOIP,CN,DIRECT
  - MATCH,Proxy
```

## 常见问题排查

| 现象 | 可能原因 | 解决方法 |
| :--- | :--- | :--- |
| 导入时提示解析失败 | 链接格式非标准 Clash 格式 | 用订阅转换器处理后再导入，或确认是 Mihomo 格式。 |
| 更新订阅超时 | 当前网络无法连接订阅服务器 | 检查网络连接，或尝试更换 DNS 后再试。 |
| 节点显示为 0 | 配置内无有效 `proxy` 字段 | 确认订阅是否已过期，或联系服务商。 |
| 测速无响应 | GeoIP / GeoSite 数据库未下载完整 | 前往 **更多 → 资源**，确保数据库已下载。 |

## 与 FlClash 的兼容性

由于 Bettbox 基于 FlClash 开发，两者在配置层面：

- **100% 兼容**：所有在 FlClash 上能运行的配置，在 Bettbox 上均可直接使用。
- **逻辑相同**：导入、测速、切换节点逻辑完全一致，无迁移成本。
- **更强性能**：Bettbox 针对大体积配置文件的加载速度做了底层优化。
