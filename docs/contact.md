## 反馈建议

书写认真、信息完整（包含必要的复现步骤和日志）的 Issue 会被优先处理。

提交前建议准备：

- Bettbox 版本与构建变体（Lite / Standard / Compatible）
- 系统版本与设备架构
- 复现步骤
- Debug 日志（应用内「日志」页面可查看）

订阅类问题请先向服务商核对订阅链接与节点格式，再判断是否为客户端问题。导入失败时，建议先在服务商后台重置订阅链接后重试。
