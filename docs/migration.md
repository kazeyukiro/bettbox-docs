# 从 FlClash 迁移到 Bettbox

如果你正在使用 **FlClash**，可以无缝切换到 **Bettbox**。两者**配置格式 100% 兼容**，迁移几乎没有成本。

---

## 为什么要迁移到 Bettbox？

相比原版 FlClash，Bettbox 带来了以下增强：

- **功耗优化**：针对 Android 后台保活机制做了策略调整，降低待机耗电。
- **内核预调优**：预设了更适合移动网络环境的 DNS 与缓存参数。
- **增强工具**：首个多平台无感智能启停、Android 端休眠支持、一键禁用 QUIC、托盘菜单增强等。
- **稳定容错**：内置双重配置检测验证，优化多平台极端场景边界问题。
- **个性化与脚本适配**：30 种测速动画、APP首页实时网速小组件、JS 覆写脚本 UI 适配。

---

## 迁移步骤

> Bettbox 与 FlClash 的配置格式 100% 兼容。

### 1. 导出配置
在 **FlClash** 中：
- 前往 **配置** 列表。
- 点击正在使用的配置条目，选择 **导出为文件**，或直接复制订阅链接。

### 2. 安装 Bettbox
- 前往官方 [Releases](https://github.com/appshubcc/Bettbox/releases/latest) 下载最新安装包。
- **注意**：Bettbox 与 FlClash 包名不同，两者可以共存，但**不能同时开启 VPN 服务**。

### 3. 导入并开启
- 在 **Bettbox** 中点击 **＋** 号，用「从 URL 导入」或「从文件导入」重新导入。
- 建议进入 **设置 → 路由设置**，重新确认「应用分流」开关，因为新安装的应用需要重新授予 VPN 权限。

---

## 迁移注意事项

### 关于包名（Package Name）
Bettbox 使用独立包名。如果你在系统设置里针对 FlClash 设置了「电池不优化」「常驻通知栏」等，需要在 **Bettbox** 上重新设置一次。

### 关于订阅更新
迁移后，请在 Bettbox 中手动执行一次 **更新订阅**，确保获取到最新的节点列表。

### 关于配置冲突
如果你在 FlClash 中开启了 **自动启动**，建议迁移后关闭它，以免两个应用在开机时竞争 VPN 权限。

:::caution 不要同时运行
Bettbox 与 FlClash 可共存于同一设备，但**请务必只开启其中一个的 VPN / TUN 服务**，否则会因争抢虚拟网卡而冲突。
:::

## 常见问题

**Q：导入 FlClash 配置后无法测速？**  
A：请检查 **更多 → 资源**，确保 GeoIP 与 GeoSite 数据库已下载完整。

**Q：原版 FlClash 的功能都在吗？**  
A：绝大多数功能都在，并新增了前述增强能力。配置与交互逻辑保持一致，无迁移成本。
