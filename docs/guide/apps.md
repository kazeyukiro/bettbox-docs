# 分应用代理

**分应用代理**（设置项名称，界面文案「配置应用访问黑白名单」）允许你指定哪些 App 的流量进入 VPN、哪些被排除在外。这对解决「网银无法登录」「本地服务访问慢」等场景非常有用。

---

## 工作原理

> **核心逻辑**：你可以自由决定哪些 App 必须经由 VPN（如社交/视频类），哪些 App 被排除在 VPN 之外（如 12306、本地银行 App），从而兼顾访问速度与本地服务的兼容性。

- 入口：**更多 → 设置 → 分应用代理**（`lib/views/tools.dart` 中该项位于「设置」分组；`lib/views/access.dart` 为功能页面）。
- 该功能作用于 VPN / TUN 接管范围，与订阅内的 `rules` 规则分流是两层不同的机制。

---

## 两种模式

界面中的模式名来自 `AccessControlMode`：`acceptSelected` 对应白名单，`rejectSelected` 对应黑名单。

| 模式 | 界面说明 | 行为 | 典型用法 |
| :--- | :--- | :--- | :--- |
| **白名单模式** | 只允许选中的应用进入 VPN | 仅勾选的应用走 VPN，其余不进入 | 只想让特定 App 走代理时 |
| **黑名单模式** | 选中的应用将被排除在 VPN 之外 | 勾选的应用直连，其余进入 VPN | 几乎全部走代理、仅个别本地 App 直连 |

:::tip 怎么选？
- 想「几乎全部走代理，仅个别本地 App 直连」→ 用**黑名单**。
- 想「默认不走 VPN，仅指定 App 走代理」→ 用**白名单**。
:::

---

## 操作步骤

1. **进入设置**：打开 **更多** 页面，在「设置」分组中点击 **分应用代理**。
2. **选择工作模式**：切换白名单 / 黑名单。
3. **搜索与勾选**：在列表中找到对应 App 并勾选。列表支持「过滤系统应用」、在「所有应用 / 仅第三方应用」间切换，长按条目可复制包名。
4. **保存生效**：设置自动保存。若 VPN 已在运行，建议重启服务以刷新路由表（界面提示「重启 TUN 后生效」）。

:::info 权限与刷新
首次进入需要授予「访问已安装应用列表」的权限；右上角提供「刷新应用列表」，新装 App 未出现时可点它。
:::

---

## 场景示例

| 场景 | 推荐配置 |
| :--- | :--- |
| 不希望游戏流量经过 VPN | 将游戏加入**黑名单**（排除在 VPN 之外） |
| 网银/本地政务 App | 加入**黑名单**，规避代理环境登录风险 |
| 海外社交/视频 | 保持进入 VPN（默认或加入白名单） |

---

## 注意事项

- **系统应用**：除非非常了解其原理，否则不建议勾选「系统组件」，这可能导致系统更新失败或推送延迟；可开启「过滤系统应用」避免误选。
- **混淆应用**：部分 App 有多个进程，若分流不生效可尝试在列表中勾选其全部相关条目；长按可复制包名核对。
- **重启服务**：修改后若发现未立即生效，重启 VPN / TUN 服务通常即可刷新路由表。
